# Arena Clash

Lösung der [Bug-Jagd beim Klassenturnier](https://github.com/Die-Spengergasse/course-wmc-5sem/blob/main/20_Typescript/20_TypescriptBasics.md#übung-bug-jagd-beim-klassenturnier-ohne-ki) mit TypeScript.

Im Ordner `arena_clash` ausführen:

```sh
npm install
npm run check
npm run start
```

`src/app.ts` enthält die Lösung, `tournament.json` die Turnierdaten und `PROTOKOLL.md` die Antworten zur Aufgabe.
Das ursprüngliche fehlerhafte Programm bleibt in `src/app.js`. Die fertige Anwendung wird nach `dist` kompiliert.
